# Pads

Provisional (M0). VSS is taken to be the top-middle pad, which sits in the peripheral
metal plane, and VCC the bottom-middle pad opposite. Pin numbers then run
counter-clockwise from VSS, as for a die seen from above. The count of pads per side
matches the pinout, and the pads that should be outputs have large driver arrays
beside them while the inputs do not. M1 confirms this by tracing the rails.
