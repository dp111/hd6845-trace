# Address lines into the register decode array, and the logic right of the array.
# Region x 15800-16950, y 12900-14700.
#
# What used to be called "the address register cells" (x 15930-16200, five of them, one per
# decode row pair) are plain inverters: the upper row of a pair arrives from outside the
# cell (from the row of register cells above the decode array, through the poly/metal
# lines traced below) and also gates the pull-down; the lower row is the inverter output.
@block areg
@requires decode

# ---------------------------------------------------------------------------------
# Row inverter. Master = pair 0 (rows y 13766 / 13851). One per row pair.
#   upper row (decode ar<k>)   : input. Crosses the cell as the top band, ends in a tab
#                                under the VCC rail; the bar hanging from it is the gate
#                                of the pull-down.
#   lower row (decode ar<k>_n) : output. Its poly is also the load gate (block at the right)
#                                and is tied to the output node by the buried contact.
# The pair's ground rail (diffusion, from the decode array) runs into the cell, is
# contacted to the VSS rail and is the source of the pull-down.
@cell areg_inv tag=0
# ground rail extension - VSS contact - pull-down channel - output node - load channel - VCC contact
D [ 15762,13782 x15972 y13761 x16036 y13790 x16128 y13785 x16200 y13832 x15762 ]
C 15950,13805 s=30x34              # VSS rail to the ground rail
C 16165,13805 s=30x34              # VCC rail to the top of the load
# upper row: from the decode array, pad under the VSS rail, top band, tab; bar = pull-down gate
P [ 15795,13753 x15942 y13741 x15956 y13731 x16182 y13773 x16160 y13751 x16018 y13843 x15993 y13752 x15962 y13777 x15795 ]
# lower row: from the decode array, bottom band, arm up to the buried contact, load gate block
P [ 15795,13838 x15968 y13860 x16040 y13805 x16066 y13845 x16087 y13768 x16130 y13865 x16062 y13882 x15945 y13864 x15795 ]
B 16036,13801:16070,13846          # load gate (= lower row) tied to the output node
@end
